# Placeholder – media still missing

Dashed box with text – marks in the draft where a photo, clip or screenshot still needs to go.

**Use when**
- Draft only: the script calls for media (photo, B-roll, screenshot) that isn't in the project yet. `text` describes exactly what is missing ("Photo: product from the front, source manufacturer").
- Every Placeholder belongs in the report (open items) so the media gets sourced.

**Don't use**
- In the final render – replace it with Video or a suitable card before `npm run render` (final).
- As a substitute for a card (number, quote, list) – those exist as components.
- Never "recreate" or invent media to avoid the placeholder.

**Props example**
```json
{ "text": "Photo: city skyline at night (still missing)" }
```
No cues.

**Layouts:** split (default), full · **9:16:** stage · **Duration:** ≥ 5 s (like the media that belongs here), default 5 s
